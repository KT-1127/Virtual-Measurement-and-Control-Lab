# バーチャル計測制御ラボ

ブロックでプログラムを作り、3D の仮想空間でロボットカーや部屋のセンサーを動かして、**計測と制御のプログラミング**を学べる教材です。
キャラクターの「チャッピー」がロボットカーに変身して走ったり、道を横切ったり、部屋で困ったり喜んだりします。

- インストール不要。ブラウザで `index.html`（トップページ）を開き、「はじめる」からラボ（`app.html`）に入ります（ラボはインターネット接続も不要）
- 23 のステージ（6章）を、やさしい順に並べています
- 各ステージは「チャッピーの説明 → お手本の動き（プログラムは見せない）→ 自分でプログラム → クリア／失敗の判定」の流れです

## 使い方

### GitHub Pages で使う
リポジトリの **Settings → Pages** で、公開するブランチ（例：`main`）とフォルダ（`/ (root)`）を選ぶと、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で誰でも使えるようになります。

| URL | ページ |
|---|---|
| `/` | トップページ |
| `/app.html` | ラボ本体（プログラミング画面） |
| `/guide/` | 説明サイト（先生・保護者向け） |
| `/terms.html` | 利用規約 |

### パソコンで使う
このフォルダをダウンロードして、`app.html` をブラウザ（Chrome / Edge 推奨）で開きます。

## ステージ

| 章 | ステージ | 学ぶこと |
|---|---|---|
| 1 じゅんばんに動かそう | 1-1 まっすぐ進もう ／ 1-2 曲がってみよう ／ 1-3 ちゅう車場に止めよう ／ 1-4 くねくね道 | 順次（進む・回る・待つ・止まる） |
| 2 くりかえしで動かそう | 2-1 池のまわりを1周 ／ 2-2 階段をのぼろう | 反復（くりかえし） |
| 3 へやをかしこくしよう | 3-1 自動ライト ／ 3-2 自動ファン ／ 3-3 人がいるときだけ ／ 3-4 スマートルーム | センサーの値で判断（分岐・かつ） |
| 4 きょりセンサーで止まろう | 4-1 かべの手前で止まろう ／ 4-2 ブロックのめいろ ／ 4-3 横断歩道のチャッピー ／ 4-4 かべ？それともチャッピー？ | 距離センサーによる計測と制御 |
| 5 明るさセンサーで走ろう | 5-1 黒い線で止まろう ／ 5-2 ライントレース（だ円） ／ 5-3 ライントレース（くねくね） ／ 5-4 線の上のチャッピー | 明るさセンサー・ライントレース・センサーの組み合わせ |
| 6 植物をそだてよう | 6-1 暗くなったら植物ライト ／ 6-2 土がかわいたら水やり ／ 6-3 朝と夕方に水やり ／ 6-4 くもりの日はライトでおぎなう ／ 6-5 全自動ビニールハウス | 生物育成：明るさ・土の水分・時刻で 植物ライト・水やりポンプ・ファンを制御 |

- 🎲 のステージ（4-1・5-1）は、実行するたびにかべや線の場所がかわるので、時間だけでは止まれません。センサーを使う必要があります
- 道を横切るチャッピーは、車の速さに合わせて飛び出してきます。ぶつかると「いたい」アクションをして失敗になります
- 3章（へや）は、実行すると明るさ・人・温度が自動でかわり、出力（LED・ファン・ブザー）が正しいかテストされます
- 6章（植物の部屋）は 1秒で1時間すすみます。明るさは時刻とくもりで決まり、土の水分は時間とともに減って、水やりポンプで増えます。水分が少なすぎる（しおれる）・多すぎる（根がくさる）と失敗です

## 仮想ロボットのしくみ

- 1マス＝30cm。はやさ50で1秒に1マス進み、はやさ50で0.5秒その場で回ると90度曲がります
- 距離センサー：前方に±20度の広がりをもち、いちばん近い物までの距離（0〜100cm）を測ります
- 明るさセンサー：車の前の下の床の明るさ（0〜100）を測ります。黒い線の上では小さくなります
- 土の水分センサー（0〜100）・時刻センサー（0〜23時）：6章の植物の部屋で使います
- 目安（さかいめの値）：明るさ 30より小さい＝暗い（ロボットカーは 50より小さい＝黒い線）、きょり 10〜20cmより小さい＝近い、温度 28℃以上（6-5は30℃）＝あつい、土の水分 30より小さい＝かわいた、昼間＝6〜17時台。ステージごとの目安は、アプリの説明・ミッション欄・センサー欄に表示されます（`js/stages.js` の RULES）

## ふりかえり

失敗してもすぐに結果の画面は出ず、仮想空間はそのまま残り、下に結果バーが出ます。
走った跡・「○秒・○マス」・ストップウォッチ・グラフを見て、どこで何秒のときにうまくいかなかったかを確かめてから、
「ヒントを見る」「もう一度」を選べます。

## 保存について

作ったプログラムとクリアの記録は、**使っているブラウザの中（localStorage）**に保存されます。
別のパソコンやブラウザには引きつがれません（今後、Firebase と連携したログイン・保存を予定しています）。

## 先生用：答え（例）の表示

ツールバー右はしの 🔑（または **Ctrl＋Shift＋K**）から**シークレットキー**を入れると「先生モード」になり、
「📖 答え」ボタンで各ステージの答えの例をブロックで見られます（そのタブを閉じるまで有効。🔓 を押すと終わります）。
答えの例は、お手本の動きと同じプログラムから自動で作られます。「このプログラムを読みこむ」で作業画面に入れることもできます。

- キーそのものはファイルに書かず、元にもどせない値（SHA-256 のハッシュ値）だけを `js/config.js` に置いています
- キーを変えるときは `tools/make-key.html` をブラウザで開き、新しいキーを入れて出てきた1行を `js/config.js` に貼りつけます
- 3回まちがえると10秒待たないと入れられません
- ※ お手本の動きを再生するために、答えのデータ自体はプログラム（`js/stages.js`）の中にあります。授業でふつうに使うぶんには見えませんが、ソースコードを読める人には分かるので、試験などの厳しい場面では使わないでください
