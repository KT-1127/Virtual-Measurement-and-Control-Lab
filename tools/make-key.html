🔑 シークレットキーの作成（先生用）

答え（例）を表示するためのシークレットキーを変えるときに使います。キーそのものはファイルに書かず、元にもどせない「ハッシュ値」だけを保存します。


    
    
    
      
  1. js/config.js をメモ帳などで開き、answerKeyHash: の行を上の1行に置きかえて保存します。
    2. 
      
  2. GitHub で公開している場合は、変更した js/config.js をアップロード（コミット）します。
    3. 
      
  3. アプリを開きなおし、右上の 🔑（または Ctrl＋Shift＋K）から新しいキーで開けるか確かめてください。
    4. 
    

    
このページで入れたキーは、どこにも送られず、保存もされません。
